# 正交参考图生产规范

## 重要
当前包只包含 **真实批准的 front 母版**。
不能用简单镜像、剪切、拉伸前视图来伪造真正侧视/背视。

需要真实生产：
- `back.webp`
- `left.webp`
- `right.webp`
- `front_left.webp`
- `front_right.webp`

## 生产方式优先级
1. 先建出真实3D模型，再从正交相机渲染六视图。
2. 若使用多视图生成AI，必须保证同一人物一致性并人工校对，再交给3D建模。

## 相机要求
- Orthographic Camera
- 同一相机高度
- 同一 focal / ortho scale
- 同一人物身高
- 同一 neutral pose
- 透明或中性灰背景

## 一致性检查
所有视图必须保持：
- 丸子头位置一致
- 发量一致
- 大眼比例一致
- 耳朵位置合理
- 白色上衣结构一致
- 袖子长度一致
- 腿长一致
- 鞋袜一致

## 禁止
- 侧视图变成另一个角色
- 背面发型自由发挥成不同发髻
- 添加母版没有的首饰/花纹
- 改衣服为汉服/战甲/裙装

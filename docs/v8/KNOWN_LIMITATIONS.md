# V8.0 已知限制与下一阶段

动作采用稀疏绘制帧，一些死亡、受击、魔法和特殊状态共享姿势；左向为镜像。不能声称每个状态都有商业级完整逐帧动画。Langa 已有展台动作，原有战斗解锁与平衡尚未完成。

服装采用二维透明附件；跳跃、攻击等大幅姿势仍可能有贴合误差，需要逐动作人工校准和重画部分袖口。生成图中的身份和比例仍可能有轻微变化。单帧缩放按完整特效边界适配，强特效动作的身体尺寸需要进一步美术统一。

11–20 关部分背景复用；21–30 关和观星塔仍是规划。背景中的装饰平台不全部对应可站立碰撞平台，现有碰撞层仍需关卡重建。当前音频为已有占位包，需要原创音效与音乐。物品掉落与商店新装备数值是初步配置，需要长期通关平衡。

验证覆盖资源加载与基础战斗输入，没有完整通关全部 20 关，没有覆盖所有 Boss 招式、存档升级边界与低端设备性能。因此不把本版标为商业发行完成或所有 bug 永久消除。

下一阶段优先建立每关真实平台碰撞、逐 Boss 通关用例和每动作装备锚点；随后增加硬直与打击反馈、精确帧动画、音效、关卡独立美术，再进行正式发行测试。

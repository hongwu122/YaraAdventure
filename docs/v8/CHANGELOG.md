# V8.0 改动记录

修复原始 Yara 身份偏离、角色展台静态图片冒充动作、脚底锚点与地形不齐、Boss 换关时旧资源缓存、第一阶段守卫未注册动作、跳跃帧截取偏移、地图 cover 式放大导致裁切、装备属性有变化但外观不变化等问题。

界面减少过粗字体和覆盖装饰，角色详情、装备比较、背包及快捷栏增加可滚动布局。动作说明改为单帧实际播放。角色外观展示使用统一运行时，衣服、鞋、武器、头饰、项链、腰饰、法宝按层叠加。清理切换关卡释放图片时的误报。

新绘制资源按透明边界自动识别图格后裁切，保存独立 PNG 帧、左右 WebP 图条和 animations.json。保留原有战斗判定时序。17 个新增装备定义连接商店和掉落。正式存档沿用 schema 5。启动端口调整为 8768，版本号统一为 8.0。

整理旧发布包、报告、测试截图与导出存档到 archive；原始参考图片与历史资源保留，方便后续美术回溯。

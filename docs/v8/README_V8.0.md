# Yara冒险日记 V8.0

本版是原 V7.0 的 2D 动作与界面修复版。双击根目录 run_YaraAdventure.bat，保持服务器窗口开启，浏览器访问 http://127.0.0.1:8768/ 。需要本机 Python 3。请通过启动器运行，不要直接双击 index.html。

原始 Q 版 Yara 的棕色丸子头、大眼睛和可爱比例重新作为角色基准。新资源已经接入游戏、角色展台、装备页和操作说明。装备现在会显示在角色身上，并保留原有属性加成。

## 文件位置

assets/v8：本版透明角色、怪物、Boss、装备、材料、原始生成图。
docs/v8：版本说明、测试范围、动作生产说明和已知限制。
qa_v8：实际浏览器截图、试玩结果和静态资源校验。
archive/releases：历代压缩包；archive/reports：旧版本说明；archive/qa：旧测试截图；archive/v7_source_before_v8：改动前备份；archive/save_exports：旧导出存档。
saves：正式游戏存档，保留原位置。V8 延续 schema 5。独立试玩 tools/v80-playtest.html 使用 qa=1，不写入正式存档。

## 已完成

地图默认按完整图片比例缩放，支持总览、定位和缩放；压低遮挡地图的覆盖层。角色展台改成实际 2D 动作播放，移除没有真实模型支持的旋转展示。统一动作帧尺寸、透明区域与脚底锚点，修复跳跃图条和裁切偏移。装备支持七个槽位可见附件，衣服和鞋采用透明外观层。补充 17 个遗漏装备定义，使生产目录内装备能被商店及掉落系统使用。

本版含 4 个角色、11 种普通怪和 13 个 Boss 外观包，560 个动作定义、286 条去重后方向图条。左右方向采用镜像。动作定义数量包括共用姿势，不能理解为 560 套独立绘制动画。经济系统现有 38 个物品定义。

## 验证与范围

20 个现有关卡均通过加载检查；第一关实测移动、跳跃、二段跳、攻击伤害、技能消耗与返回菜单。七槽装备加成、存档校验与篡改拒绝通过。新动作图条的文件存在性、透明度、帧宽和主角攻击时序检查通过，JavaScript 语法检查通过。

这次没有逐关完整通关，也没有完成商业发行所需的长时间平衡与性能测试。详细限制见 docs/v8/KNOWN_LIMITATIONS.md。地图 21–30 和观星塔仍为后续规划入口。

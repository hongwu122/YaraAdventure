# YaraAdventure V8.2 更新说明

2026-10-06。此次按界面、资源、体验的顺序收尾，以界面和资源稿为重点。

装备页固定人物在左上区域，当前穿戴在人物下方，右侧装备物品栏单独滚动，悬停比较与点击锁定详情。七个穿戴槽完整显示。背包物品图与名称留出间距，修复旧短窗口样式造成的窄列排版；商店按装备、丹药、材料、任务分类。按钮改为直角，修行设施窗口居中并使用统一深蓝与淡金配色，ESC 关闭后返回我的洞天。洞天左上入口为装备、背包、行商、心法；山海录在主界面。

开始冒险创建一个命名存档并绑定一个角色；继续冒险恢复最后一次旅程；读取存档显示八格。声音、画质、存档分类可点击，支持当前旅程立即保存、导出、导入空位以及切换读取。原有存档可迁移，导入不覆盖已有旅程。测试使用隔离的存档目录。

五行角色补齐，墨羽显示名改为红舞，新增土系辰露。五名角色使用独立透明动作图，后十关使用十张不同的场景，地面按场景主题对应。修复第八关秋叶场景误用冰雪地面。补齐十二个装备图标并统一衣甲、鞋履的图标与穿戴素材。山海录整合原角色展台，提供动作、左右方向、暂停及逐帧查看；技能默认播放对应动作，四套特效可查看六帧循环。

通关窗口包含下一关、重新挑战、返回舆图、返回主界面。暂停窗口使用同一主色调并补齐返回入口。既有 v8.0 压缩包已放入 archive/releases；v8.1 修改前的源文件保存在 archive/v81_source_before_v82。

# V8.2 小问题修补与洞天美术补充（2026-10-06）

本次直接更新游戏源码。历史完整 V8.2 ZIP 是修补前版本；本修补包覆盖安装到 V8.2 根目录即可。修补包不包含任何玩家 saves 文件，不覆盖原有旅程。

修复起跳 jump_up、下落 jump_fall 的动作映射。缺帧时只显示单人立绘，不再将整张动作表绘制为玩家。启动索引按角色去重，使用最新版索引。五行角色攻击、技能恢复前摇、有效攻击与收招时序，补充安全默认时序。修正岚歌和辰陆复制配置中遗留的 Yara entityId。技能美术特效提前载入。

主菜单标题强制横排；被隐藏的旧地图、旧角色入口继续隐藏。洞天装备、背包、行商、心法移动至右上方半透明导航条。七个设施名称默认显示；悬停显示等级和说明。按钮增加轻微位移与亮度反馈，保持直角外形。物品界面的三个分类入口靠右排列。

新增五张独立透明 PNG：藏经阁、丹炉、静修台、聚灵阵、灵泉。使用生成式美术制作，保留材质、雕刻、光影与透明光晕。全部接入山海录和设施详情；聚灵阵、灵泉另接入洞天场景，其他设施利用已有背景中的对应物件。原有木鱼与药圃美术继续使用。素材不是圆圈、线条或建筑示意占位图。

读取存档新增删除按钮；开始冒险时已有位置可以确认覆盖。删除与覆盖分别显示确认提示。删除档另保留最近 16 条浏览器回收副本；服务器保留原有文件备份。操作功能使用独立临时存档验证，未删除玩家已有旅程。

正式第 4 格新增「Yara满级测试」：Lv.100，主线 20 关开放且三星，47 阶修行路线的最终境界，七设施最高等级，12 个 Yara 心法节点解锁，999 技能点，9999999 灵石，30 件装备以及丹药、材料。当前角色经验系统没有硬性等级上限，因此 Lv.100 是便利测试等级，最高境界才是当前内容的实际终点。读取该格即可测试，也附单独 JSON 导入文件。

# Yara V4.4 resource structure

- `source_master.webp` — approved white-outfit Yara master.
- `showcase/` — high-resolution fallback art for character showcase.
- `textures/` — 2K modeling reference plates. They are reference plates, not fake UV maps.
- `model/` — GLB production contract, skeleton and AnimationClip interface.
- `combat_v44/` — normalized 512×512 action strips and metadata.

The approved master is the identity source of truth. Do not replace it with a redesigned face/outfit/body ratio.
